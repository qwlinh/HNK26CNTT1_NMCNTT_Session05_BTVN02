# Hệ điều hành: Windows (PowerShell)

## 1: Đoạn kịch bản Terminal hoàn chỉnh:
PowerShell


mkdir drink_module


cd drink_module


New-Item coffee.txt, tea.txt


## 2: Giải thích chi tiết các lệnh:
mkdir drink_module: Lệnh mkdir tạo một thư mục mới có tên là drink_module tại vị trí hiện tại.


cd drink_module: Lệnh cd (change directory) dùng để di chuyển vào bên trong thư mục drink_module vừa tạo.


New-Item coffee.txt, tea.txt: Lệnh New-Item trên PowerShell cho phép tạo đồng thời nhiều file trống (coffee.txt và tea.txt) cùng lúc bằng cách phân tách tên file bằng dấu phẩy.
